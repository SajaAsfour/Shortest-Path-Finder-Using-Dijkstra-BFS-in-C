# 🌍 Shortest Path Finder Using Dijkstra & BFS in C

## 📌 Overview
This repository contains my **C implementation** of a **Graph-based Shortest Path Finder** using **Dijkstra's Algorithm** and **Breadth-First Search (BFS)**. The program reads a list of cities and their distances from a file and allows users to find the shortest path between two cities.

## 🛠 Features
- ✅ **Load cities and distances from a file** (`cities.txt`).
- ✅ **Graph representation using adjacency lists**.
- ✅ **Find the shortest path using:**
  - Dijkstra's Algorithm (Weighted shortest path).
  - BFS (Unweighted shortest path).
- ✅ **Handles up to 500 cities dynamically**.
- ✅ **Outputs shortest paths and distances to a file (`shortest_distance.txt`).**

## 📂 Contents
- 📜 **C Source Code:** Implementation of Dijkstra & BFS algorithms.

## 📌 Requirements
- C Compiler (GCC, Clang, or MSVC)
- Basic understanding of graph algorithms (Dijkstra, BFS)
